O que o mercado está exigindo?

Análise qualitativa dos principais requisitos identificados no estudo de mercado.

Competências Técnicas

Forte foco em fundamentos de desenvolvimento web, controle de versão robusto (Git) e entendimento prático de APIs rest e bancos de dados relacionais.

Competências Comportamentais

A habilidade de comunicação clara, pró-atividade para resolução de problemas e capacidade de trabalho em equipe foram apontadas como diferenciais vitais.

Local vs Nacional

Vagas locais valorizam infraestruturas híbridas e conhecimento de stacks clássicos (PHP/SQL), enquanto as nacionais focam em frameworks modernos e modelo remoto.

Síntese do Aprendizado

A análise sistemática das vagas locais e nacionais permite compreender quais conhecimentos técnicos e soft skills devem ser priorizados na nossa formação profissional para atender com precisão às demandas do mercado.

Stack Escolhida & Plano de Desenvolvimento:
A stack selecionada para aprofundamento é Java + Spring Boot + PostgreSQL/MySQL + Git + Docker. O foco para este semestre inclui conteinerização com Docker, testes unitários automatizados, construção de APIs REST completas e noções de nuvem (AWS/Azure) com pipelines CI/CD, aplicando tudo em projetos no GitHub.
